# Đưa project lên GitHub

## Cách tải lên bằng giao diện web

1. Giải nén bộ project.
2. Tạo repository tên **`wazuh-elk-suricata-intrusion-detection-lab`**.
3. Chọn **Add file → Upload files**.
4. Tải toàn bộ **nội dung bên trong** thư mục project lên để `README.md` nằm ở thư mục gốc của repository. Không chỉ tải file ZIP lên.
5. Commit với thông điệp `docs: add Wazuh ELK detection lab and evidence`.
6. Kiểm tra README, ảnh và các liên kết demo sau khi tải lên.
7. Ghim repository vào profile nếu muốn làm nổi bật project.

## Nội dung mục About

**Description:**

Wazuh + ELK Stack + Suricata intrusion detection lab documenting Kerberoasting detection, malicious-file removal, and SSH brute-force containment with original experiment evidence.

**Suggested topics:**

## Phạm vi bộ project

README và các trang demo được trình bày bằng tiếng Anh theo phong cách ba mẫu đã cung cấp. Nội dung tập trung vào kiến trúc, kết quả và bằng chứng của ba demo được chọn. Ảnh trích trực tiếp từ báo cáo PDF và tài liệu demossh.docx, giữ nguyên nội dung và độ phân giải ảnh nhúng.

Bộ project không kèm toàn bộ PDF, mật khẩu cài đặt, API key, mã độc, hay mã nguồn triển khai được tự suy diễn. Các ảnh cấu hình là minh chứng của môi trường thực nghiệm; không phải bộ cấu hình đầy đủ có thể chạy ngay.
